# Differences between type hinting, type checking and data validation in Python 

- Type hinting: tells what we expect the type of a variable to be. Similar to the word type annotation (some slight differences). Improves code readability and maintainability.  

- Type checking: static analysis that makes sure that we are sticking to the declared types before the code even runs.

- Data validation: happens at <b>runtime</b> to make sure data meets our requirements.
